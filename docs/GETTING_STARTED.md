# VISHU Phase 1 — Local development

## Prerequisites
- Windows 10/11 for the first target desktop acceptance (Linux/macOS remain development targets).
- Node.js 22+ and npm.
- Python 3.11+.
- Ollama, or an OpenAI-compatible local model server.

## Install and launch
From the repository root:

1. Create a Python environment: python -m venv .venv
2. Activate it using the normal command for your operating system.
3. Install API requirements: python -m pip install -r backend/requirements.txt
4. Install frontend requirements: npm install
5. Install and start Ollama, then install the default model: ollama pull qwen2.5:3b
6. Start VISHU desktop: npm run dev

VISHU launches a local FastAPI service on a dynamically chosen loopback port. It creates its SQLite database in Electron's user-data folder. The backend session token is randomly generated by the Electron main process and never sent to React.

## Optional settings
- VISHU_PYTHON: absolute path to the Python interpreter containing backend dependencies.
- VISHU_MODEL: model ID, default qwen2.5:3b.
- VISHU_LLM_BASE_URL: OpenAI-compatible API URL, default http://127.0.0.1:11434/v1.
- VISHU_LLM_API_KEY: optional API credential, only in the backend environment.

Environment variables must be set in the terminal before running the app. Never put a provider secret in a VITE_ variable.

## Testing
- Python API: python -m pip install -r backend/requirements-dev.txt, then python -m pytest
- React typecheck and bundle: npm run build

## Current limitations
- A standalone Vite browser page intentionally cannot call the authenticated backend. Run through Electron.
- Voice, device connectivity, permissions-brokered tools and rich memory are not implemented yet.
- The first slice is intended for source-based development. Installer packaging, final production hardening and cross-platform acceptance remain in progress.
- Backend availability does not guarantee an AI model is installed. Missing models produce an error instead of a simulated AI response.
